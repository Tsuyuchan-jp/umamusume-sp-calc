# 更新履歴

公開版の主な変更を記録する。細かい開発コミットは Git 履歴を参照。

形式は [Keep a Changelog](https://keepachangelog.com/ja/1.0.0/) に近いが、セマンティックバージョニングは緩め（`0.1.x` = 公開後の軽量改修）。

**運用**:
- 版上げ（リリース）を伴わない変更は **[Unreleased]** にためる（追加・変更・修正など、開発者／ユーザーに意味のある内容のみ）
- 次の版上げ時に Unreleased の内容をその版の節へ移し、Unreleased を空に戻す
- 作業キュー・後追いタスクは [TODO.md](./TODO.md) へ（CHANGELOG に TODO 節を置かない）

## [Unreleased]

### 変更

- **カードピッカー刷新（backlog #4）**: R3 土台（紫クロム＋統合プレビュー）＋ R1 部品（トグル絞込・色ドットタイプ・選択バッジ／金枠）。棚は固定高さ＋内スクロール（絞込でダイアログ高さが跳ねない）

### 修正

- **育成アイコン重複**: `chr_icon` キーを `race_dress_id` 正本に統一（カード名⇔衣装名一致。`piece_icon` 不使用）。オグリ等の 2↔3 入れ替えを解消。特殊 `91xxxxx` 2枚のみ固有 race 無し
- **カードピッカー**: 選択中の二重枠（ピンク outline＋金）を金枠＋バッジのみに整理。検索は controls 帯へ再構成しグローバル input スタイルの干渉を解消
- **結果枠の角丸リム**: DOM を紫クロム＋白本体の二段構成に整理。白いパネル上への負マージン載せをやめ、角の白い縁を解消
- **編成枠の角丸リム**: 同様に `.app-header`（紫）＋ `.deck-body`（白）へ整理
- **スプリット左「カード」枠上ラベル**: 不要のため削除（見切れ対策の overflow 変更はせず表記自体を廃止）

### 変更

- **結果作業台 W-H**: レギュ儀式バー（セグメント即適用）＋4列表（ON／スキル／必要SP／由来）。条件・Lv はサブ行。文言を ONスキル数／ONスキルをコピー／列ON に統一。手動 OFF はレギュ変更でも維持
- **スプリット詳細ペイン**: 見た目再設計。閉じ方は再タップ／Esc／**カード帯クリック**（モーダル風）。選択肢のスキル＋Lv 二重表示を解消
- **結果作業台の見た目パリティ**: H5ツール行（含めるタグ・レギュ・並び・コピー）、含めるを緑トグル化。表の列／レギュ要件／計算は維持
- **見た目 P0**: 世界観背景を同梱の横長 `assets/ui/uma-world.png` に切替（空＋芝）。パネル幾何タイル。スプリット左ゾーン分け。ヘッダーは編成パネル先頭の g-brand。レイアウトはモック型（上クロム 1480 固定、本文 gallery 1180／split 1480）。**主要面の隙間を `--layout-stack` / `--layout-gutter` で統一**（gallery／split／auto）
- **デュアルUI（スプリット H1）**: 左ドックを 2×3＋育成横並びに。合計＋前提を上部コマンド化（下端バーは split 時非表示）。A 詳細は左ペイン（ギャラリーはダイアログ維持）。B 方針はスプリット見た目確認後に再検討
- **スプリット足元／上部バー**: リンク・RMJを短いチップ化（「C」ラベル廃止・長文による崩れ解消）。シナリオ自動は折りたたみ。上部コマンドを app-main と同幅に揃え、モック寄りのブランド＋TOTAL＋前提構成へ
- **B方針確定**: 件数チップ→モーダルは不採用。サポカ自動は列下要約、シナリオ自動は足元折りたたみが本線（UX/handoff 更新・モーダル残骸削除）
- **シナリオチップ**: 表示をスキル名へ。リンクは編成で金化したとき金トーン＋「金」マーク。RMJも金表示。トータルバーは案A（合計幅固定・前提右寄せ）＋前提チップをモック pbtn 寄せで gallery/split 統一
- **デュアルUI（移植 第2弾）**: 列下イベントを要約＋詳細ダイアログ化（金最上段・未選択削除）。自動は列下に金スキル名のみ。継承詳細をトータルバー上展開へ。foundation を H5 紫クロム寄りに再塗装
- **デュアルUI（移植 第1弾）**: ギャラリー／スプリット／幅自動の切替。スプリットは左編成・右作業台。自動計上Bは件数チップ→モーダル（インライン折りたたみ廃止）。シナリオリンクと RMJ を足元帯で横並び（C）
- **Visual Foundation**: `app/css/foundation.css` でデザイントークン＋主要面を再塗装。M PLUS Rounded 1c、S-A カード面、インク系＋合計コーラル／ON ティール。色は CSS 変数で後から差し替え可能
- **画面UX（質感パス）**: 二マグネット（上段編成／下段作業台）＋弱い scroll-snap。上段はサポカ6列ギャラリー、選択式イベントは列下、シナリオ・継承詳細は上段足元の薄い帯
- **前提操作**: 上段の前提チップを廃止し、下部固定トータルバーを唯一の正本に（切れ者・トレLv・継承ON/OFF）。バーは D3 トーン
- **サポカ絞込**: 編成欄の検索・絞込を廃止。ピッカー内にイベント対応のみ／SSR／タイプチップを集約

- **結果表の由来表示**: 種別バッジ（トレヒント／育成ウマ娘／イベント／シナリオ／継承）＋詳細名。ホバーで由来ごとのヒントLv。採用Lvと一致する由来を強調
- **トレヒント由来の詳細**: フルネームではなく略称（タイプ＋キャラ短縮。例: `スピタップ` / `友人たづな`）
- **サポカイベント表示名**: 同じくタイプ＋略称（例: `スピタップ 心のカギは` / `スタドトウ …`）
- **呼称**: タップダンスシチーは当アプリでは「タップ」（旧「シチー」は廃止）
- **結果表の並び**: 表直上のセグメント（スキルID／由来種別／必要SP）。既定はスキルID。スマホ向けに十分なタップ領域
- **由来バッジ**: 「所持」表記を「育成ウマ娘」に変更。詳細は衣装タイトル無しのキャラ名のみ（例: `アーモンドアイ`）
- **由来ツールチップ**: `スキル名 / 種別 LvN`（金行で下位と金の由来が並ぶとき、どちらへのヒントか分かる）
- **由来種別ソート**: 採用ヒントLvの由来をバッジ先頭に置き、行の並びもその採用由来をキーにする。採用バッジは左アクセント＋非採用の沈みで強調
- **初期編成**: 育成 `[The Changer]アーモンドアイ`（112901）＋常用サポカ6枚（エアグルーヴ / テイオー / タップ / ドトウ / ヤング / たづな）
- **カードピッカー検索**: ひらがな入力を修正。キャラ名のみ対象＋ローマ字検索（英字はかな化して照合: `ai`→`アイ`。長音は `aamondo` / `a-mondo`。衣装タイトルは対象外）

- **ピッカー Round 1**: タイプ絞込で選択中カードが全タイプに出る `keepId` すり抜けを修正。選択強調をピンク outline で強化（ホバーでも消えない）
