## 結論

**ユーザー向けのデザイン仕上げパスに、いま必須の P0 はない。**  
デュアル骨格・H5 トーン・Zen Maru／世界観背景・ピッカー Round 1・B方針・足元チップは入済み。「ぱっと見モック前の TODO」に見えたのは、**コードに残る旧 CSS や、FB当時の文言を未解決のまま残していたため**。

| 初版の項目 | 再判定 | 理由 |
|------------|--------|------|
| フォントかすれ対策 | **実質済（要人間の最終印象）** | Zen Maru・ウェイト 500/700/900・`smoothing: auto` 済。「かすれる」指摘はそれ以前 |
| style↔foundation 一本化 | **見た目は済／コード掃除は任意** | foundation 後読みで上書き。`style.css` の旧緑・`#888` は chore |
| ピッカー Round 1 | **済** | タイプは keepId すり抜けなし・ピンク outline。実機問題の再指摘なしならクローズ |
| パネル bg.webp 質感 | **未・任意（P2）** | モック差分として唯一はっきり残る。必須ではない |
| 世界観／存在感 | **済（好みの微調整のみ）** | `.world-bg`＋紫クロムヘッダー済 |
| 前提チップ幅 | **対応済寄り** | `min-width` 等あり。再指摘がなければクローズ |
| ヘッダー中央寄せ | **未・任意（P2）** | 当初から仕上げ可の位置づけ |

## いま Open にしてよいもの

### 人間の目だけ（実装タスクにしない）

- **いまの画面で、まだ気になる見た目・操作があるか？**  
  - 無ければデザイン大改修の見た目パスはクローズでよい  
  - あればその箇条書きだけを新規 Open にする（古い一覧は使わない）

| 項目 | メモ |
|------|------|
| パネル `bg.webp`／幾何タイル | H5 パリティ。外部URL依存に注意 |
| ヘッダー／modebar 中央寄せ | 見た目のみ |
| `style.css` 旧色・旧ウェイトの掃除 | メンテ用 chore。見え方のブロッカーではない |
| 継承パラメータ編集 UI | 保留のまま |
