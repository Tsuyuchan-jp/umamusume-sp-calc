## 1. 主目的（ユーザー合意）

- **主目的**: モダンな Web アプリらしい見た目と触り心地への刷新
- **維持する**: 計算機としての UX（真の必要 SP・前提が合計の近く・PC 主戦場・可読性・近似しない）
- **維持しない**: いまの古い HTML/CSS 的な見た目そのもの
- **画面骨格（2026-08-02 確定）**: **デュアル**（ギャラリー H2 ⇄ スプリット H1）。旧・二マグネット単独はギャラリー側の祖先
- **ゲーム UI っぽさ**: 可読性・道具性・統一感が保てれば OK（忌避しない）
- **詳細指示より**: エージェントに統一デザインで任せる方が結果が良い（ユーザー合意）

詳細・イベント A/B/C: [UX.md](./UX.md)（画面重心・イベント情報設計）

## 2. 画面構造（確定・デュアル）

```text
【共通】合計 SP ＋ 前提（切れ者・トレLv・継承）は合計の近く
【共通】イベント層 A=選択式 / B=自動計上(確認) / C=シナリオ系

ギャラリー（H2）
  上: 育成+サポカ（圧縮）・列下は要約（A）＋短い自動表示可（B）
  足元: シナリオリンク | RMJ（C）・シナリオ自動は足元インライン（確認のみ）
  下: 結果表
  下端バー: 合計＋前提

スプリット（H1）
  上: 合計＋前提（現状は下端バー共通。H5の上部コマンド化は未）
  左: ワイドドック（カード大）・フォーカスで A 詳細ペイン / B は読取専用（現状はダイアログ代用）
       足元に C＋シナリオ自動
  右: 結果表（広く）
```

- 切替: 手動トグル ＋ 幅自動（目安 1200px）
- 左右タブ壳・強制フルページスナップは **採用しない**（snap 削除済）
- サポカ自動Bは **列下に載せる**（件数モーダルは廃止・本線確定）。シナリオ自動は足元の折りたたみ
- 継承パラメータ編集UIは **保留**（ON/OFFのみ。個数・Lv・base は hidden 既定値）

モック正: [mockups/hybrid-h5-dual.html](./mockups/hybrid-h5-dual.html)
