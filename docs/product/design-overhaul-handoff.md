## 5. 実機フィードバック（2026-08-02・要対応）

### 方向性

- **合う** が、まだ **弱い**（存在感・コントラスト不足）
- **フォントがかすれている**（特にラベル・絞込見出しなど細い文字）

### かすれ対策の候補（次チャットで検討）

- `font-weight: 400` の細部が薄い → ラベルは **500〜700**、本文 **500** 寄り
- `-webkit-font-smoothing: antialiased` が細線を弱める → `auto` や `subpixel-antialiased` を試す
- 薄いグレー文字（`--text-muted`）＋細ウェイトの組み合わせ → コントラスト比を上げる
- Google Fonts の **display=swap** で一瞬細く見える → `optional` / プリロード
- `foundation.css` と `style.css` の二重定義で古い薄い色が残っている箇所を洗い出し、**トークン一本化**

### ピッカー

- [ ] タイプ切替でダイアログ高さが変わる → `min-height` は入れたが再確認
- [ ] **選択中が全タイプに出る**（バグ）— `supportMatchesFilters` の `keepId` すり抜けを修正
- [ ] 選択強調が弱い／ホバーで選択リングが消える → foundation で一部対応済み、要実機確認

### 列下イベント（未実装）

- [ ] ラジオ → **パネル選択**
- [ ] 複数選択時 **金スキル側を最上段**（`skills.json` の `rarity === 2`）
- [ ] **自動イベントでも金スキルのみ列下表示**（「このサポカはこの金をくれる」）
- [ ] **「未選択」削除**（ゲーム上ありえない。既定は `defaultChoiceId`）

### トータルバー

- [ ] 継承詳細をバーに統一（**上展開 H1**）。足元帯から継承を外す
- [ ] トレLv UI 改善（セグメント化など）— チップ1行化は済
- [ ] ON/OFF でチップ幅が変わる — `min-width` は入れたが文言・固定幅の再調整

### 足元帯

- [ ] 「シナリオリンク（1択）」「シニア12月 RMJ（1択）」見出し削除
- [ ] シナリオリンクと RMJ を **横並び**

## 6. 推奨作業順

ユーザー方針（2026-08-02 更新）: 現行 CSS に引っ張られて大きな改修が難しいため、**先に独立モックで方向を決める**。

0. **独立ビジュアルモック（進行中）** — 比較検討中  
   - [v5](./mockups/redesign-proposal-v5.html)（**v2見た目 × v4骨格**・有力候補）  
   - [v4](./mockups/redesign-proposal-v4.html) / [v3](./mockups/redesign-proposal-v3.html) / [v2](./mockups/redesign-proposal-v2.html)  
   現行 `app/` は触らない。フィードバック後に移植方針を決める。
1. **方向確定後** — モックのトークン／構造を `app/` へ移植（Foundation 再塗装 or 段階置換）
2. **Round 1 — 正しさ** — ピッカー絞込バグ、選択強調
3. **Round 2 — 列下イベント＋足元帯**
4. **Round 3 — 継承バー上展開**

計算式・events JSON・タイプ印合成は触らない。push / Pages は v1.0.0 までしない。

### 保留（モック確定まで）

- Foundation 2（現行 foundation.css 上での強度アップ）は、モック方向が「現行の延長」でよいと分かった場合のみ再開。
