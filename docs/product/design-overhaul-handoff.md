- **主目的**: モダンな Web アプリらしい見た目と触り心地への刷新

- **詳細指示より**: エージェントに統一デザインで任せる方が結果が良い（ユーザー合意）

## 5. 実機フィードバック（2026-08-02・要対応）

### 方向性

- **合う** が、まだ **弱い**（存在感・コントラスト不足）
- **フォントがかすれている**（特にラベル・絞込見出しなど細い文字）

### かすれ対策の候補（次チャットで検討）

- `font-weight: 400` の細部が薄い → ラベルは **500〜700**、本文 **500** 寄り
- `-webkit-font-smoothing: antialiased` が細線を弱める → `auto` や `subpixel-antialiased` を試す
- 薄いグレー文字（`--text-muted`）＋細ウェイトの組み合わせ → コントラスト比を上げる
- Google Fonts の **display=swap** で一瞬細く見える → `optional` / プリロード
- `foundation.css` と `style.css` の二重定義で古い薄い色が残っている箇所を洗い出し、**トークン一本化**

### ピッカー

- [ ] タイプ切替でダイアログ高さが変わる → `min-height` は入れたが再確認
- [ ] **選択中が全タイプに出る**（バグ）— `supportMatchesFilters` の `keepId` すり抜けを修正
- [ ] 選択強調が弱い／ホバーで選択リングが消える → foundation で一部対応済み、要実機確認

### 列下イベント（第2弾）

- [x] ラジオ → **パネル選択**／要約＋詳細ダイアログ（ギャラリー・スプリット共通。左ペインは未）

- [x] **自動イベントでも金スキルのみ列下表示**
- [x] **「未選択」削除**（既定は `defaultChoiceId`）

### トータルバー

- [ ] トレLv UI 改善（セグメント化など）— チップ1行化は済
- [ ] ON/OFF でチップ幅が変わる — `min-width` は入れたが文言・固定幅の再調整
