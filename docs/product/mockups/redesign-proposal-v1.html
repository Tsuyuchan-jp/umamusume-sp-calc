この案の狙い（現行コードから離れた点）

  • ブランドをヒーローに — 細いヘッダーではなく Dela Gothic の製品名が最初の信号。
  • 芝レーンの合計バー — トータルバーをレース場の芝グリーン＋ゴールド縁に。数値は結果発表っぽいゴールド。
  • ウマ娘寄りの色 — アクセントはピンク（信号）、紙面は青空＋緑、ON は芝グリーン。
  • ウェイトを落とさない — UI は 700/900 固定。かすれの主因だった 400＋薄いグレーを使わない。
  • 列下はパネル — ラジオ行ではなく選択パネル。金スキルを最上段に置く前提の見た目。
  • 継承はバーの上 — 足元帯から外し、継承 ON で合計バー直上にシートが出る（下のバーで切替可）。
  • 足元は短く横並び — 「1択」見出しを消し、リンク／RMJ／自動計上だけ。
