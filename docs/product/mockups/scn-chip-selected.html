リンク／RMJ — 選択中デザイン（再モック）

課題: 「金スキル属性」と「選択中」がどちらも金系だと区別しづらい。
下の「現在の実装」は本番 CSS の再現です。案A〜Eは未承認の提案（チップをタップで選択切替できます）。採用案を返事ください。本実装は承認後のみ変更します。

現在の実装

本番どおり

非金ON＝ピンク塗り。金ON＝濃い金塗り＋白／紫の二重リング。属性と選択の両方で金が強くなる。

案A — リングのみ

提案

金の塗りは常に薄いまま（属性専用）。選択は紫リングだけ。濃金塗りをやめて属性と選択を分離。

提案
