## 一文

攻略記事（note 等）に貼れる **共有用の横長カード** を、現在の設計からワンクリック（優先: コピー）で出す。アプリ画面の切り抜きではなく、**専用レイアウト**。モード非依存。

## 用途（優先順）

| 順 | 用途 | 含意 |
|----|------|------|
| 1 | **攻略記事・掲示板への貼り付け** | 情報密度と「投稿して恥ずかしくない」見た目。横長（16:9 寄り）が note にも合いそう |
| 2 | X 投稿 | 横長・読みやすさ |
| 3 | Discord | 埋め込み耐性（副次） |

自分用メモ単体は主目的ではない（メモリ機能が担う）。

## 載せる／載せない

| 区分 | 内容 |
|------|------|
| **必須（最低限）** | 育成＋サポ6、前提チップ、合計 SP |
| **欲しい** | 設計名（メモリ名）、**計上スキル数** |
| **レイアウト次第で載せたい** | 選択イベント（特に **金スキル関連**）。見せ方はモックで決める |
| **見た目候補（モック確認中）** | **型C寄り**（左＝SP・条件、右＝育成要約＋サポ3×2グリッド）。企業スライド構図。立ち絵は保留 |
| **付記まで可** | 除外は **件数のみ**（リストは出さない） |
| **載せない** | 除外の中身リスト、結果表（スキル一覧の詳細） |

UX 初期方針（顔＝6＋合計＋前提）は土台として維持。記事用途のため、金イベント要約とスキル数を上乗せ候補にする。

## 操作・置き場・モード

| 項目 | 方針 |
|------|------|
| 操作 | **保存（PNG）＋クリップボードコピー**。優先は **コピー** |
| ボタン置き場 | **未決**（モックで判断） |
| 見た目 | **専用共有カード**（アプリ上段の切り抜きではない）。細部はモック次第 |
| モード | **常に同じカード**（ギャラリー／スプリットどちらからでも同一出力） |
| アスペクト | **横長寄り**を第一候補。最終はモックで確定 |
| ブランド表記 | **未決**（アプリ名・URL の有無はモックで見る） |

## v1 成功条件

**投稿・記事に載せても恥ずかしくない見た目**（品質優先）。  
「ワンクリックで出せる」は必須だが、見た目を犠牲にして速度だけ取る方針にはしない。

## やらない（この機能の範囲外）

- 結果表まるごとの画像化
- 除外スキルの列挙
- レイアウトモード別の別デザイン出力
- 計算ロジック・events JSON の変更
- モック承認前の本実装

## 未決（モックで決める）

1. 金スキル関連イベントの載せ方（無し／短行／枠ごと要約）
2. スキル数の定義表示（例:「計上 N スキル」の文言と位置）
3. 除外件数チップの有無
4. ボタン置き場・ブランド表記の有無
5. 横長カードの具体サイズ（記事埋め込み想定）

## 進め方（確定）

- 薄い三連比較より **主案1枚を完成品質で出す** → 採用 / 方向違い / 惜しい＋一言
- 部品の逐次微調整はしない（クオリティ低下防止）。差し替えは丸ごと
