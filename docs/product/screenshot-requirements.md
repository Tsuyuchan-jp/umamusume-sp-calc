## 載せる／載せない

| 区分 | 内容 |
|------|------|
| **必須** | 育成＋サポ6、前提（切れ者・トレ・継承・レギュ）、合計 SP、計上スキル数 |
| **載せる** | 金スキル（選択・計上ON）と手動除外を作業面の主役に。全スキル列挙はしない |
| **載せない** | レギュ非互換の除外リスト、結果表詳細、育成所持・進化の金、カード面のツール名 |

## 作業面レイアウト（金 vs 手動除外）

カード左の作業エリア（`.work`）の高さは固定（16:9 内）。**金スキルを優先**し、除外は残りだけ使う。

| 優先 | 要素 | 方針 |
|------|------|------|
| 1 | **金スキル** | 内容の高さを先に確保。除外に押し潰されない |
| 2 | **手動除外** | 金のあと残った縦スペースのみ。通常は 2〜3 行分の下限余白 |
| — | **溢れ** | 収まらない除外は列挙せず、末尾に **「他 N 件」** |
| 例外 | 金が極端に多い | v1 は金を優先し続ける。金側の省略は本実装時に要判断（通常は不要） |

```
workHeight = 作業エリアの高さ
goldHeight = 金パネルの内容高さ（行数から算出 or measure）
excludeMax = workHeight - goldHeight - gap
→ excludeMax 内に収まるチップだけ描画、残りは「他 N 件」
```
