# umamusume-sp-calc

ウマ娘プリティーダービー向け。育成完了時に「取得可能スキルをすべて取る」ための**理論必要 SP** をブラウザで算出するツールです。

## 使う（公開版）

**インストール不要。** 次の URL をブラウザで開くだけです。

**https://Tsuyuchan-jp.github.io/umamusume-sp-calc/app/**

### 制限事項（告知用）

> ウマ娘 SP 計算ツール（**v1.0.5**）。**トレセン軒シナリオのみ**・**ガチ想定**（クラシック大盛況・シニア超盛況・育成終了スキル固定）・**優先40サポカのイベント**対応（U-tools+mdb 抽出正本）。ゲーム更新後はデータが古くなる場合があります。非公式・非商用です。

### 使い方の流れ

1. 広い画面では上部のレイアウト切替（ギャラリー／スプリット）で画面構成を選ぶ（狭い画面はギャラリー固定）
2. 育成ウマ娘を選ぶ（初期値あり）。編成タイトルは見出し下で編集可
3. サポカを最大6枚選ぶ（初期は**イベント対応40種**に絞込。全件表示は「イベント対応のみ」を外す）
4. イベント／シナリオ（リンク・ラーメン等）を必要なら調整
5. **合計 SP**を確認（除外・切れ者・継承固有・**トレヒントLv**も可。ギャラリーは下部、スプリットは上部）
6. 対人レギュ向けに、結果の**バ場／距離／作戦**絞込で合わないスキルを自動除外できる
7. 前回の続きは自動復元。名前付き保存はヘッダー「メモリ」。共有は広い画面はモードバー右端、狭い画面は結果見出し横の画像コピー／画像保存。初期に戻すときは編成見出し右の「リセット」

わからないときは、画面上部ヘッダー右の **「使い方」** から説明書（ヒントLvの算出・よくある疑問など）を開けます。

## 注意

- **シナリオはトレセン軒のみ**（当面固定）
- **シナリオスキルはガチ想定** — 盛況段階の切替はなし（常に大盛況／超盛況＋終了を計上）
- **イベントは優先40サポカ** — 全サポカ網羅ではない（[一覧](docs/product/PRIORITY_SUPPORTS.md)）。新規追加は最新の課金必須 SSR を原則とする
- HTML をローカルでダブルクリックしても動きません（公開 URL か、開発者向けの HTTP 配信が必要）

## 機能

- デュアルレイアウト（ギャラリー／スプリット。広幅は手動切替、狭幅はギャラリー固定）
- 育成ウマ娘所持スキル（最大覚醒レベル想定・ヒントLv3）＋サポカ6枚（**トレヒント**・既定Lv5、オプションで3–5）
- サポカ絞込（イベント対応のみ・デフォルトON、SSR、タイプ、検索・ローマ字可）
- 結果スキル絞込（バ場／距離／作戦・発動条件タグ表示・自動除外・並び替え）
- 結果パネルスキル数表示（ON/全件・継承固有は個数分）
- イベント／シナリオスキル選択式（列下要約・自動確認・足元帯）
- 金＋白コスト合算（実機検証済み）
- 切れ者トグル・スキル除外
- **トレヒントLv**（3 / 4 / 5・既定5。編成サポカのトレヒントを一括指定）
- 継承固有（汎用行・2〜6本・baseSp200・一律Lv）
- セッション自動復元／設計メモリ（上限20件・サムネ一覧）／編成タイトル／初期リセット
- 編成スクショ共有（画像コピー／画像保存・WebP）
- ヘッダー **「使い方」** 説明書モーダル（ヒントLv・FAQ・制限事項）
